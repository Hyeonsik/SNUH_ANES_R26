# 인계보드

동기들끼리 턴별·교수님별 인계, 꿀팁, 공부 내용을 함께 쌓는 웹 보드입니다.

- 화면: `docs/` → GitHub Pages
- 데이터와 비밀번호 확인: `backend/Code.gs` → 구글 시트에 붙인 Apps Script 웹 앱
- 저장소에는 코드만 있고 인계 내용·비밀번호·이름은 없습니다. 데이터는 비밀번호를 맞힌 요청에만 내려갑니다.

## 권한

| 비밀번호 | 할 수 있는 일 |
|---|---|
| 관리자 | 전부. 보드·섹션·동기·교수님 명단·비밀번호 관리 |
| 동기 | 인계 추가·수정·삭제, "아직 유효해요" 확인 |
| 보기 전용 | 읽기와 검색만 |

## 처음 설정 (한 번만)

1. 구글 드라이브에서 새 스프레드시트를 만든다. 이름은 자유.
2. 확장 프로그램 → Apps Script. 기본 코드를 지우고 `Code.gs` 내용을 붙여넣는다.
3. 맨 위 `INITIAL_PASSWORDS` 세 개를 바꾸고, `INITIAL_MEMBERS` 에 동기 이름을 적는다. 저장.
4. 상단 함수 목록에서 `setup` 선택 → 실행 → 권한 승인.
   "확인되지 않은 앱" 경고가 나오면 고급 → 이동을 누른다. 본인이 만든 스크립트라 괜찮다.
5. 배포 → 새 배포 → 유형 "웹 앱" → 실행: **나** / 액세스 권한: **모든 사용자** → 배포.
   나온 URL(…/exec)을 복사해 `docs/config.js` 의 `API_URL` 에 넣는다.
6. 저장소 Settings → Pages → Branch `main`, 폴더 `/docs` → Save.
   1~2분 뒤 `https://<계정>.github.io/<저장소>/` 로 열린다.

## 인계장 파일

보드마다 hwp·pdf·pptx·docx 파일(25MB 이하)을 올리거나 드라이브 링크로 등록할 수 있다. "새 버전으로 교체"를 하면 이전 파일은 이전 버전으로 남는다.
올린 파일은 시트 주인 드라이브의 `인계보드 파일` 폴더에 저장되고 "링크가 있는 사람은 보기 가능"으로 공유된다. 링크는 비밀번호를 통과한 사람에게만 보인다.
Apps Script 권한은 `appsscript.json` 에서 "이 스프레드시트"와 "이 앱이 만든 드라이브 파일"로 좁혀 두었다.

## 이후 운영

- 구조(보드, 섹션, 동기, 교수님)와 비밀번호는 관리자 설정 화면에서 바꾼다.
- `Code.gs` 를 고친 경우: Apps Script에 붙여넣고 배포 → 배포 관리 → 연필 → 버전 "새 버전" → 배포. URL은 그대로 유지된다.
- 비밀번호를 잊으면 `INITIAL_PASSWORDS` 를 새로 적고 `resetPasswords` 를 실행한다.
- 백업은 스프레드시트 자체다. `entries` 시트가 인계, `history` 시트가 수정 이력.
- 1년 넘게 확인되지 않은 인계는 흐리게 보인다. 아직 맞는 내용이면 말풍선을 눌러 "아직 유효해요"를 누른다.
- 환자 식별 정보는 쓰지 않는다.

## 로컬 테스트

```
node test/server.js --seed   # http://localhost:8787 , 비밀번호 admin-1234 / dongi-1234 / view-1234
```
`test/server.js` 가 Apps Script 객체를 흉내 내어 실제 `Code.gs` 를 그대로 실행한다.
